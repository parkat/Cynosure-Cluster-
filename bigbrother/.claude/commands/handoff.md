description: Write a session handoff so the next session can resume cleanly.
---

Write `plan/handoffs/YYYY-MM-DD-session-N.md` (auto-increment N for today) containing:

1. **What was done this session** (bullets, with file paths)
2. **What's next** (specific actionable items, file paths, expected outputs)
3. **Anything blocked** (and on what)
4. **Exact commands to resume work**
5. **Open questions for the human** (if any)

Keep under 50 lines. After writing, update plan/CURRENT_PHASE.md to reflect new state.
